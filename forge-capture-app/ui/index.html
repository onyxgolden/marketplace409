    How FORGE Capture works

    Capture modes

    • Full monitor — captures the whole selected monitor, right now.
    • Window — pick a window from the list, then Capture. (Windows only for now — on Linux use monitor or region.)
    • Region (drag on screen) — the screen dims; drag a rectangle, or press Esc to cancel.

    Keyboard shortcuts

    • PrintScreen — open the Capture window
    • Shift+PrintScreen — start a region capture
    • Ctrl+PrintScreen — window capture (pick the window, then Capture)
    • Alt+PrintScreen — capture the current monitor now
    • Esc — cancel a region pick

    On Linux, the global shortcuts work in X11/Xorg sessions; on Wayland the compositor may block them — everything still works from this window.

    Where captures go

    Every capture is saved automatically as PNG + a .forge.json sidecar in the captures folder shown under “Session captures” (~/.local/share/forge-capture/Captures on Linux). Use Copy on any capture to put the image on the clipboard.
