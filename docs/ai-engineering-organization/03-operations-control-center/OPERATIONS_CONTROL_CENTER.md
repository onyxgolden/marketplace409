## Daily Startup

1. Identify active project.
2. Load project charter.
3. Load current repository state.
4. Load active objective.
5. Load unresolved incidents and decisions.
6. Verify authority level.
7. Recommend the safest next action.

## Daily Shutdown

1. Record completed work.
2. Record validation results.
3. Record unresolved failures.
4. Record repository state.
5. Update active objective.
6. Generate continuation instructions.
