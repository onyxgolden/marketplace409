# FORGE Product Documentation

## Purpose

This directory preserves the product vision, product principles, product operating model, product decisions, and long-term product evolution of FORGE.

Product documentation answers:

- Why does FORGE exist?
- Who does FORGE serve?
- What products and shared capabilities belong in the platform?
- What customer outcomes should FORGE improve?
- How are ideas evaluated before implementation?
- How does each initiative support the total vision?

Product documentation does not replace repository inspection, software architecture, implementation roadmaps, or source code.

## Permanent Rule

No strategic product idea should exist only in conversation.

Strategic ideas must be captured, linked to the total vision, and version controlled before the discussion is considered complete.
