# FORGE Design Principles

## Purpose

Define the user experience principles shared by every FORGE product.

## Principles

### Product Before Technology

Users experience products—not architecture.

### Explain Before Asking

Provide context before requesting user input.

### Progressive Disclosure

Reveal advanced functionality only when it becomes valuable.

### Trust Through Transparency

Recommendations should explain evidence, assumptions, uncertainty, and confidence.

### Opportunity Over Advertising

Present opportunities, never intrusive advertising.

### Minimize Repetitive Data Entry

Information entered once should be reused whenever appropriate.

### Reuse Shared Platform Capabilities

Avoid duplicate experiences when a shared platform service already exists.

### Consistent Navigation

Navigation patterns should remain familiar across all FORGE products.

### Decision-Centered UX

Every major screen should help users answer:

- What happened?
- Why did it happen?
- What should I do next?

### Mobile First

Important workflows should remain practical on phones and tablets.

### Accessibility

Products should be understandable and usable by the widest practical audience.

### Long-Term Trust

Every design decision should strengthen customer confidence in the platform.
